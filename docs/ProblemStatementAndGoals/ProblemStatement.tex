\section{Goals}

The primary goal of the platform is to provide a centralized and structured system for managing the capstone project process. The platform will improve the experience for students, academic supervisors, industry sponsors, and administrators by making project information easier to access, manage, and coordinate.

\subsection{Core Goals}

\begin{enumerate}
    \item \textbf{Centralized Capstone Project Management:}
    Provide a single platform where capstone projects can be submitted, viewed, managed, and tracked throughout their lifecycle.

    \item \textbf{Project Discovery:}
    Allow students to search and filter available projects based on factors such as skills, technologies, project type, industry, supervisor, and availability.

    \item \textbf{Student and Stakeholder Profiles:}
    Allow students, academic supervisors, and industry sponsors to create profiles containing relevant information such as skills, interests, experience, and project preferences.

    \item \textbf{Team Formation:}
    Support students in finding potential teammates based on shared project interests, complementary skills, and project requirements.

    \item \textbf{Project Interest and Application Management:}
    Provide students with the ability to express interest in projects and allow supervisors as well as sponsors to review and manage interested students.

    \item \textbf{Standardized Project Submissions:}
    Provide a consistent project submission format that ensures important information, such as objectives, requirements, required skills, and expected deliverables, is clearly presented.

    \item \textbf{Administrative Management:}
    Provide administrators with tools to manage users, projects, project availability, and project assignments.

    \item \textbf{Project Lifecycle Tracking:}
    Track projects through key stages, including proposal submission, approval, discovery, team formation, assignment, and completion.
\end{enumerate}

\subsection{Stretch Goals}

The following features may be implemented if sufficient development time and resources are available.

\begin{enumerate}
    \item \textbf{Team Compatibility Matching:}
    Recommend potential teammates with respect to their skills, interests, and project preferences.

    \item \textbf{Intelligent Project Recommendations:}
    Create a recommendation system that makes suggestions on projects to students based on the student's skills, interests, and preferences.

    \item \textbf{Student--Project Matching:}
    Create a matching protocol that evaluates the compatibility between students and project requirements.

    \item \textbf{Analytics Dashboard:}
    Provide administrators with statistics regarding project demand, student engagement, applications, and project availability.

    \item \textbf{Advanced Applicant Management:}
    Provide supervisors and industry sponsors with tools for reviewing, comparing, and shortlisting students interested in their projects.

\end{enumerate}
